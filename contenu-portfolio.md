## 4. Études de cas

### Cas 1 – Assistant médical intelligent (LLM + RAG + vision)
*Concours Dell Technologies, 2024*
- **Contexte** : concevoir un assistant capable de répondre à partir de documents médicaux et d'analyser des images.
- **Ce que j'ai fait** : pipeline RAG (récupération de documents, LLaMA 3 via Ollama, LangChain, ChromaDB), module d'analyse d'image (YOLOv8, PyTorch), API Flask, interface Next.js, stockage MongoDB.
- **Résultat** : prototype complet combinant texte et image, présenté en concours.
- **Stack** : LLaMA 3, LangChain, RAG, ChromaDB, PyTorch, YOLOv8, Flask, Next.js, MongoDB.

### Cas 2 – Chatbot IA de support interne (grande entreprise)
*2025, contexte confidentiel anonymisé*
- **Contexte** : les équipes support recevaient en continu les mêmes demandes d'authentification et de gestion des accès.
- **Ce que j'ai fait** : conception et développement d'un chatbot interne qui automatise les réponses à ces demandes récurrentes, dans le respect des règles de sécurité et de contrôle d'accès.
- **Résultat** : réduction de la charge de support sur ces demandes. (Chiffre à confirmer avec toi avant publication.)
- **Stack** : Python, API REST, contrôle d'accès par rôles, Docker, GitLab CI/CD.

### Cas 3 – Plateforme de gestion de dossiers étudiants
*Projet full stack / automatisation, 2025–2026*
- **Contexte** : gérer tout le cycle de vie des dossiers étudiants, avec des traitements récurrents et des échanges de documents.
- **Ce que j'ai fait** : plateforme web avec traitements planifiés automatiques, échange de documents par SFTP, workflows de notifications, stockage objet MinIO, déploiement conteneurisé derrière Nginx.
- **Résultat** : processus manuels remplacés par des traitements automatisés et traçables.
- **Stack** : Python, Flask, React, PostgreSQL, Docker, Nginx, MinIO, Linux.

### Cas 4 – Maintenance prédictive d'équipements industriels
*Projet ML, OCP, 2023*
- **Contexte** : anticiper les pannes de machines (stackers) à partir de données capteurs.
- **Ce que j'ai fait** : modèle de machine learning sur images thermiques infrarouges et signaux de vibration, exposé via une API FastAPI et une interface interactive Streamlit.
- **Résultat** : outil capable de signaler des anomalies avant la panne.
- **Stack** : Python, TensorFlow, FastAPI, Streamlit, vision par ordinateur.

*Cas en réserve* : services FastAPI de vision par ordinateur + streaming Kafka sur AWS (Artéka, 2024-2025) ; pipeline MLOps de détection de clients (Airflow/MLflow/DVC).
